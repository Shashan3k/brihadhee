## 3. Disambiguation

- "Brihadhee" is close to "Brihadeeswarar" (the Thanjavur temple) and to other spellings, so search engines and AI assistants can confuse them.
- **Rule:** wherever the name first appears, pair it with "restaurant" and "Anna Nagar" (for example "Brihadhee restaurant, Anna Nagar East"). Never use the name alone in a bio, post title, article pitch or listing name field beyond the exact registered name.
- Keep the registered name field exactly "Brihadhee". Do not add keywords to the name.
