# AI crawler policy

Status: **decided 2026-11-05: allow training crawlers** (client brief).

## Current state of `robots.txt`
Generated by `src/pages/robots.txt.js`. It allows all crawlers (`User-agent: *`, `Allow: /`) and names these **search and user-fetch** agents explicitly so a future blanket rule cannot block them by accident:

| Agent | Operator | Purpose |
|---|---|---|
| `OAI-SearchBot` | OpenAI | ChatGPT search index |
| `ChatGPT-User` | OpenAI | fetches a page when a ChatGPT user asks |
| `PerplexityBot` | Perplexity | Perplexity search index |
| `Perplexity-User` | Perplexity | fetches a page for a Perplexity user |
| `Claude-SearchBot` | Anthropic | search results |
| `Claude-User` | Anthropic | fetches a page for a Claude user |

## Training crawlers: not named, decision needed
These are **not** listed. Because the default rule is `Allow: /`, they are currently *allowed by default*. If the owner wants to block them, add an explicit `Disallow: /` group for each.

| Agent | Operator | Note |
|---|---|---|
| `GPTBot` | OpenAI | model training |
| `ClaudeBot` | Anthropic | model training |
| `Google-Extended` | Google | controls use of crawled content for Gemini training and grounding; does not affect normal Google Search or AI Overviews |
| `CCBot` | Common Crawl | open web archive used by many models |

Earlier work (commit `9627494`) explicitly allowed `ClaudeBot` and `Google-Extended`. That was removed on 2026-11-05 because this is the owner's choice, not an engineering default.

## Trade-off to explain to the owner
- Allowing training crawlers can make the business better known to future models; blocking them has no effect on Google Search ranking and does not remove the site from AI *search* answers (those use the search agents above).
- Blocking is a policy choice, not an SEO requirement.

## Caveat
Crawlers read `robots.txt` only from the host root. While the site is served from `shashan3k.github.io/brihadhee/`, this file is not at the root and is ignored; it takes effect on a custom domain (see `docs/seo/audit.md`, section 2).
